## 2. Technologies Used
* **Backend:** Python (Flask)
* **Frontend:** HTML, Bootstrap (CSS framework), Jinja2 Templates
* **Database:** MySQL (using PyMySQL)
* **Security:** bcrypt (for password hashing)
* **Image Uploads:** Flask, Werkzeug (secure_filename), and Python's os and uuid modules for handling and storing uploaded images.

---

## Prerequisites
- MySQL Server installed and running locally
- Python 3.8+ installed
- MySQL Connector Python (`pip install mysql-connector-python flask`)
